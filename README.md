## 📤 Where do I push?

Put each year's material in its own folder:

```
python-sig/
└── <year>/                 e.g. 2026/
    ├── day-1-<topic>/      slides (PDF **and** the editable .pptx / Google Slides link)
    ├── day-2-<topic>/
    ├── code/               demo code, starter projects, notebooks
    └── assignments/
```

1. Open the [`2026/`](2026/) folder, then **Add file → Upload files** (or use Git).
2. Add the year to the *Editions* table above, with a link.

New to Git? Follow [**How to push to PISB GitHub**](https://github.com/PICT-IEEE-Student-Branch/.github/blob/main/CONTRIBUTING.md).
